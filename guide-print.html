인쇄 사용방법

내 파일을 매장 PC에서 열어 종이로 뽑는 방법입니다. 프로그램별 인쇄설정도 함께 안내합니다.

사용방법 전체 🖨️ 인쇄 📋 복사 📄 스캔 팩스 ✨ 코팅 📚 제본
!
잘못된 인쇄설정으로 인한 오출력은 환불이 어렵습니다. 출력 전 반드시 미리보기로 전체 페이지를 확인해 주세요. 화면에 보이는 그대로 인쇄됩니다.

인쇄하는 방법 PRINT

내 파일을 매장 PC에서 열어 종이로 뽑는 서비스입니다. PC에서 파일을 보내고, 복합기에서 찾아 출력합니다.

1
PC · 프린터 선택

파일을 열고 [인쇄] → 흑백 · 컬러 · 증명서 중 선택

2
PC · 설정하고 미리보기

양면 · 종이 크기 · 장 수를 정하고 전체 페이지를 확인하세요

3
PC · 비밀번호 4자리 입력

휴대폰 뒷 4자리 입력. 증명서 전용은 9999 자동

4
복합기 · 인쇄 → PC

[인쇄] 메뉴를 누르고, 동그란 [PC]를 누르세요

5
복합기 · 번호 조회 · 시작

PC에서 정한 비밀번호 4자리(PIN)를 넣고 → 목록을 고르고 → [시작]을 누르세요

6
복합기 · 확인 · 결제

금액 확인 화면(과금정보)에서 [확인]을 누르세요 → IC 카드는 꽂고, 휴대폰 페이는 화면 아래에 대세요

복합기 · PC 화면 사진으로 보기 SCREEN

실제 화면을 단계 순서대로 보여드립니다. 위 <인쇄하는 방법>의 1~6단계와 같은 순서입니다.

1
프린터 선택

PC에서 파일 열기 → 프린터 고르기
흑백 / 컬러 / 증명서전용(PIN9999) 선택

2
비밀번호 4자리(PIN) 입력

휴대폰 번호 뒤 4자리를 넣으세요
증명서전용은 9999가 자동으로 들어가요

3
복합기에서 인쇄 메뉴 → PC 선택

매장 내 복합기로 이동 → 인쇄(PRINT) 메뉴 선택 → PC 선택
화면이 꺼져 있으면 화면을 눌러 켜세요

4
비밀번호(PIN) 넣고 [확인] → 목록 고르기 → [시작] 누르기

PC에서 정한 비밀번호(PIN)를 넣고 [확인] → 목록에서 파일 고르기 → [시작] 누르기

종이 크기가 Letter(레터)로 되어 있으면 PC에서 A4로 다시 바꾸세요
5
금액 확인 (과금정보)

총 가격·페이지수·컬러 여부 확인
맞으면 [확인]을 누르세요

6
카드 결제

카드 찍는 기계에서 말소리가 나오면 IC카드를 꽂으세요
삼성페이·애플페이: 와이파이 표시가 있는 면에 대세요

삼성페이·애플페이는 현대카드 마스터만 가능

인쇄 꿀팁

인쇄할 때 자주 놓치는 부분입니다.

종이 크기는 A4로

종이 크기를 반드시 A4로 정하세요. (Letter 크기는 기계가 읽지 못해요)

전송 후 30분 안에 출력

전송 후 복합기에서 30분 내 출력하지 않으면 파일이 자동 삭제됩니다.

PDF로 저장 후 전송

PDF 파일로 저장 후 전송하면 폰트 깨짐 없이 출력됩니다.

Adobe Acrobat Reader PDF

매장 PC에 설치된 PDF 전용 프로그램입니다. PDF 파일은 편집 상태가 그대로 유지되어 가장 정확하게 출력됩니다.

1
파일 열기

USB나 이메일에서 PDF 파일을 열면 Acrobat Reader로 실행됩니다.

2
인쇄 메뉴 선택

위쪽 [파일] → [인쇄]를 누르거나 프린터 그림을 누르세요. 키보드 Ctrl과 P를 같이 눌러도 돼요

3
프린터 선택

흑백 · 컬러 · 증명서전용 중에서 고릅니다. 컬러로 뽑으려면 반드시 컬러 출력을 선택하세요.

4
인쇄 설정

양면 · 종이 크기 · 장 수 · 인쇄할 페이지를 먼저 정하세요.

5
미리보기 확인 후 인쇄

첫 장만 보지 마세요. 전체 페이지를 넘겨 확인한 뒤 [인쇄]를 누릅니다.

한컴 한글 뷰어 HWP

매장 PC에는 편집 기능이 없는 열람 전용 뷰어가 설치되어 있습니다. 파일을 만든 환경과 다르면 화면이 달라질 수 있습니다.

1
파일 열기

HWP 파일을 열면 한글 뷰어로 실행됩니다.

2
인쇄 메뉴 선택

[파일] → [인쇄]를 누르세요. (Ctrl과 P를 같이 눌러도 돼요) 프린터와 인쇄 설정을 정하세요.

3
화면이 달라 보일 수 있어요

글꼴·줄간격·표가 틀어지거나 원본에 없던 기호(□)가 나타날 수 있습니다.

4
PDF로 저장해 오세요

한글에서 [다른 이름으로 저장] → PDF로 바꿔 오시면 원본 그대로 출력됩니다.

MS 오피스 WORD · EXCEL · PPT

워드 · 엑셀 · 파워포인트 파일의 인쇄 설정 방법입니다. 프로그램마다 화면 구성은 다르지만 [파일] → [인쇄]로 들어가는 순서는 같습니다.

1
인쇄 영역 지정

상단 [페이지 레이아웃] → 페이지 설정 → [시트] 탭에서 인쇄 영역을 인쇄할 칸들을 마우스로 누른 채 끌어서 고르세요.

2
한 페이지에 맞추기

페이지 설정의 [페이지] 탭에서 자동 맞춤을 선택하고 용지 너비 · 높이를 1로 두면 잘리지 않고 한 장에 담깁니다.

3
여백 · 가운데 정렬

[여백] 탭에서 여백 크기를 조정하고, 페이지 가운데 맞춤(가로 · 세로)을 체크하면 보기 좋게 정렬됩니다.

크롬 · 엣지 브라우저 캔바 · 웹 PDF

캔바 · 미리캔버스 · 웹 디자인 프로그램 · 아이패드 메모 앱에서 만든 PDF는 브라우저로 열어서 인쇄하면 정상적으로 인쇄됩니다.

🔎 내 파일이 열린 브라우저를 먼저 확인하세요 엣지와 크롬은 인쇄 화면이 달라요

PC에서 파일이 엣지(Edge)로 열려 있으면 아래 엣지 방법, 크롬(Chrome)으로 열려 있으면 아래 크롬 방법(1~5단계)을 따라 하세요. 개인식별번호를 넣고 인쇄 작업 창 확인(5단계)까지 끝나면, 아래로 내려가 복합기에서 인쇄하기로 이어서 하세요. 엣지 · 크롬 · 알씨 모두 똑같아요.

e엣지(Edge)에서 인쇄하기1~5단계
1
[인쇄] 누르기

브라우저에서 인쇄할 파일이 열린 상태에서 [인쇄] 또는 프린터 모양을 누르세요.

2
프린터 선택

프린터에서 흑백출력 또는 컬러출력 프린터를 선택하세요.

⚠️ 컬러출력 프린터를 선택했다면 '색' 칸에서 [색]을 선택하고, 오른쪽 미리보기가 컬러로 나오는지 반드시 확인하세요.
3
인쇄 옵션 선택 · 확인

[기타 설정]을 눌러 용지 사이즈, 양면/단면, 한 면에 인쇄할 페이지 수 등 인쇄 옵션을 선택하거나 확인하세요.

4
[인쇄] 누르고 번호 입력

아래쪽 [인쇄] 버튼을 누르면 개인식별번호 입력창이 나와요. 아무 숫자 4자리를 넣으세요. 내 핸드폰 번호 뒤 4자리를 추천해요.

이 번호(PIN번호)는 복합기에서 내 문서를 찾을 때 쓰는 임시 비밀번호 같은 거예요. 꼭 기억하세요!
5
인쇄 작업 창 확인

흑백출력 또는 컬러출력 인쇄 작업 창을 보세요.
목록이 하나도 없으면 인쇄 작업이 복합기로 전송된 상태예요.
목록이 남아 있으면 없어질 때까지 기다려 주세요.

PC에서 할 일은 여기까지예요!아래 ‘복합기에서 인쇄하기’로 이어서 하세요 ⬇
C크롬(Chrome)에서 인쇄하기1~5단계
1
[인쇄] 누르기

인쇄할 파일이 크롬에서 열린 상태에서 [인쇄] 또는 프린터 모양을 누르거나, 키보드 Ctrl과 P를 같이 누르세요.
인쇄 설정 창이 나와요. 왼쪽은 미리보기, 오른쪽은 인쇄 옵션 설정 창이에요.

2
프린터(대상) 선택

오른쪽 설정 창에서 '대상'이 프린터를 고르는 곳이에요. 누르면 기본으로 흑백출력 프린터가 나와요.
컬러출력이 안 보이면 아래의 [더보기...]를 누르세요. 전체 프린터 목록이 나와요.
흑백출력 또는 컬러출력 프린터를 선택하세요.

⚠️ 컬러출력 프린터를 선택했다면 '컬러' 칸(레이아웃 아래)에서 [컬러]를 선택하세요. 그리고 왼쪽 미리보기가 컬러인지, 인쇄할 모든 페이지가 컬러로 나오는지 반드시 확인하세요.
3
인쇄 옵션 선택 · 확인

[설정 더보기]를 누르면 용지 크기, 양면, 시트당 페이지 수 등 인쇄 옵션이 나와요. 원하는 대로 선택하거나 확인하세요.

4
[인쇄] 누르고 번호 입력

알씨 사진 · 이미지

사진이나 이미지 파일을 인쇄할 때 사용합니다. 한 장에 여러 장 배치도 가능합니다. 매장 PC 바탕화면의 알씨 아이콘으로 사진을 열면 됩니다.

1
파일 열고 인쇄 메뉴

사진을 알씨로 연 뒤 상단 [메뉴] → [인쇄하기]를 선택합니다. 키보드 Ctrl과 P를 같이 눌러도 돼요

2
프린터 선택

컬러출력 또는 흑백출력 중에서 고릅니다. 컬러 사진은 반드시 컬러출력을 선택하세요.

3
용지 크기 · 방향

왼쪽 아래 [프린터 설정]을 눌러 용지 크기(A4 · A3 등)와 세로 / 가로를 정합니다.

4
크기 설정

[크기설정] 탭에서 용지 크기에 맞춤을 체크하면 사진이 용지에 꽉 차게 인쇄됩니다. 비율을 지키려면 용지 비율에 맞춤을 선택하세요.

5
여백 · 위치

[여백/위치] 탭에서 위 · 아래 · 좌 · 우 여백(mm)과 사진을 놓을 위치를 정합니다.

6
장 수 정하고 인쇄

[기타] 탭에서 인쇄할 장 수를 정하세요. 왼쪽 미리보기로 전체를 확인한 뒤 [인쇄]를 누르세요.

7
[인쇄] 누르고 번호 입력

[인쇄]를 누르면 개인식별번호 입력창이 나와요. 아무 숫자 4자리를 넣으세요. 내 핸드폰 번호 뒤 4자리를 추천해요.

복합기에서 인쇄하기 엣지 · 크롬 · 알씨 공통

PC에서 개인식별번호를 넣고 인쇄 작업을 보낸 뒤에 하는 단계예요. 엣지, 크롬, 알씨 모두 똑같아요.

복1
복합기에서 인쇄 → PC → 번호 입력

복합기로 이동해서 [인쇄] → [PC]를 누르세요.
PIN번호 입력란에 PC에서 넣은 4자리 번호를 입력하고 [OK]를 터치하세요.

복2
내 문서 목록 확인

목록이 나오면 문서 이름, 작업 시간, 흑백/컬러, 양면/단면, 페이지 수, 용지 사이즈 등 목록에 나오는 내용을 꼼꼼히 확인하세요.
내 문서가 맞는지, 인쇄 옵션이 원하는 대로 되어 있는지 봐 주세요.

복3
목록 누르고 [시작]

내 문서 목록을 터치한 뒤 [시작] 버튼을 터치하세요.
목록이 여러 개라면 위쪽의 [모두 인쇄]를 누르거나, 인쇄할 목록만 여러 개 터치한 뒤 [시작]을 누르세요.

복4
금액 확인 (과금정보)

마지막으로 과금정보 창이 나와요. 내용을 모두 꼼꼼히 확인하고, 가격까지 맞으면 [확인]을 터치하세요.

⚠️ 과금정보 창의 페이지 수나 금액이 내가 알고 있는 것과 다르면 결제하지 마세요.
