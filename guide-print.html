내 파일을 매장 PC에서 열어 종이로 뽑는 방법입니다. 프로그램별 인쇄설정도 함께 안내합니다.

사용방법 전체 🖨️ 인쇄 📋 복사 📄 스캔 팩스 ✨ 코팅 📚 제본
!
잘못된 인쇄설정으로 인한 오출력은 환불이 어렵습니다. 출력 전 반드시 미리보기로 전체 페이지를 확인해 주세요. 화면에 보이는 그대로 인쇄됩니다.

인쇄하는 방법 PRINT

내 파일을 매장 PC에서 열어 종이로 뽑는 서비스입니다. PC에서 내 파일을 열어 인쇄 작업을 하고 나서, 복합기로 이동하여 문서를 개인식별번호로 찾아 결제하면 출력이 됩니다.
⚠️ PC에서 인쇄 작업을 마친 뒤 복합기로 이동하여, PC에서 입력한 개인식별번호로 조회하고 결제해야 마지막으로 출력이 돼요. 결제하기 전에는 인쇄물이 나오지 않습니다.

1
파일 열고 프린터 선택

PC에서 파일 열기 → [인쇄] → 프린터 고르기
흑백 / 컬러 / 증명서전용(PIN9999) 선택

💾 내가 가져온 파일을 먼저 매장 PC에 저장한 다음, 그 파일을 열어서 인쇄하세요
📄 파일 형식마다 인쇄옵션 설정 방법이 다릅니다.
인쇄설정방법 — 내 파일 형식을 눌러 보세요
2
비밀번호 4자리(PIN) 입력

휴대폰 번호 뒤 4자리를 넣으세요
증명서전용은 9999가 자동으로 들어가요

3
복합기에서 인쇄 메뉴 → PC 선택

매장 내 복합기로 이동 → 인쇄(PRINT) 메뉴 선택 → PC 선택
화면이 꺼져 있으면 화면을 눌러 켜세요

4
비밀번호(PIN) 넣고 [확인] → 목록 고르기 → [시작] 누르기

PC에서 정한 비밀번호(PIN)를 넣고 [확인] → 목록에서 파일 고르기 → [시작] 누르기

종이 크기가 Letter(레터)로 되어 있으면 PC에서 A4로 다시 바꾸세요
5
금액 확인 (과금정보)

총 가격·페이지수·컬러 여부 확인
맞으면 [확인]을 누르세요

6
카드 결제

카드 찍는 기계에서 말소리가 나오면 IC카드를 꽂으세요
삼성페이·애플페이: 와이파이 표시가 있는 면에 대세요

삼성페이·애플페이는 현대카드 마스터만 가능

인쇄 꿀팁

인쇄할 때 자주 놓치는 부분입니다.

종이 크기는 A4로

종이 크기를 반드시 A4로 정하세요. (Letter 크기는 기계가 읽지 못해요)

전송 후 30분 안에 출력

전송 후 복합기에서 30분 내 출력하지 않으면 파일이 자동 삭제됩니다.

PDF로 저장 후 전송

PDF 파일로 저장 후 전송하면 폰트 깨짐 없이 출력됩니다.

PDF 파일은 어도비 아크로벳 리더 뷰어에서 열립니다 PDF

매장 PC에 설치된 PDF 전용 프로그램(어도비 아크로벳 리더)입니다. PDF 파일을 열고 프린터 모양이나 [파일] → [인쇄]를 누르거나 키보드 Ctrl과 P를 같이 누르면 아래 인쇄 화면이 나와요.

  1. 1
    프린터에서 흑백출력 또는 컬러출력 프린터를 선택하세요.
  2. 2
    페이지 크기 조정 및 처리에서 반드시 '맞추기'가 선택되어 있어야 해요.
  3. 3
    ⚠️ 'PDF 페이지 크기에 따라 용지 소스 선택(Z)'에 체크가 없어야 해요!
    체크가 되어 있으면 용지 크기를 A4 · B4 · A3로 골라도 복합기에서 조회할 때 Custom이라고 표시돼요. 반드시 체크를 풀고 인쇄 작업을 진행하세요.
  1. 4
    아래 [페이지 설정...]을 눌러 원하는 용지 크기를 선택하세요.
  2. 5
    미리보기에서 전체 페이지가 정상으로 보이는지 확인하세요.
    컬러출력을 골랐다면 오른쪽 작은 미리보기가 반드시 컬러로 보여야 해요.
    컬러로 안 보이면
    1. 위쪽 '회색 명암(흑백)으로 인쇄'에 체크되어 있는지 보고, 되어 있으면 체크를 풀어요.
    2. 풀었는데도 흑백이면 PC를 다시 켜고(재부팅) 파일을 다시 열어서 진행해요.
    3. 그래도 흑백이면 그 파일을 엣지나 크롬에서 열어 컬러출력 프린터를 선택하고, 미리보기가 컬러인지 확인한 뒤 인쇄하세요. 엣지·크롬 방법 보기
  3. 6
    모든 인쇄 옵션 설정이 끝나면 [인쇄] 버튼을 누르세요. 개인식별번호 입력창이 나와요.
PDF 인쇄 옵션은 여기까지예요! [인쇄]를 누르면 개인식별번호 입력창이 나와요.위 ‘인쇄하는 방법’ 2단계(비밀번호 4자리 입력)부터 이어서 하세요 ⬆

한컴 한글 뷰어 HWP

매장 PC에는 편집 기능이 없는 열람 전용 뷰어가 설치되어 있습니다. 파일을 만든 환경과 다르면 화면이 달라질 수 있습니다.

  1. 1
    프린터 선택: 프린터 목록에서 원하는 프린터(흑백출력 또는 컬러출력)를 누르세요.
  2. 2
    용지 크기 · 단면/양면: [설정] 버튼을 누르면 [프린터 속성] 창이 나와요.
    A. [기본] 탭에서 인쇄 방향과 단면/양면을 고르세요.
    B. [용지] 탭에서 [원본 문서 크기]와 [출력 문서 크기]를 모두 출력하고자 하는 사이즈(A4 · B4 · A3)로 똑같이 맞추세요.
    ⚠️ 파일에 따라 [출력 문서 크기]를 설정하지 않으면, 복합기에서 조회할 때 용지 크기가 Letter(레터)나 Custom(커스텀) 등 한글 파일 크기로 나와요.
  3. 3
    인쇄 매수를 정하세요.
  4. 4
    인쇄할 페이지 범위를 고르세요. 전체 또는 특정 페이지만 인쇄하려면 [일부분]을 고르고 페이지 번호를 입력하세요.
  5. 5
    한 면에 인쇄할 페이지 수: 한 면에 한 페이지는 [기본 인쇄]를 고르세요. 한 면에 여러 페이지는 [모아 찍기]를 고르고 인쇄할 페이지 수를 입력하세요.
  6. 6
    모든 설정이 끝났으면 [인쇄] 버튼을 눌러 진행하세요.
    ※ 공용 PC라서 인쇄 설정이 매번 달라져요. 원하는 인쇄 옵션을 모두 확인하고 설정한 뒤 인쇄하세요.
💡 파일을 만든 PC와 글꼴이 달라서 글꼴 · 줄 간격 · 표가 틀어지거나 원본에 없던 기호(□)가 나올 수 있어요. 한글에서 [다른 이름으로 저장] → PDF로 바꿔 오시면 원본 그대로 출력됩니다.
한글 인쇄 옵션은 여기까지예요! [인쇄]를 누르면 개인식별번호 입력창이 나와요.위 ‘인쇄하는 방법’ 2단계(비밀번호 4자리 입력)부터 이어서 하세요 ⬆

MS 오피스 WORD · EXCEL · PPT

워드 · 엑셀 · 파워포인트 파일의 인쇄 설정 방법입니다. 프로그램마다 화면 구성은 다르지만 [파일] → [인쇄]로 들어가는 순서는 같습니다.

  1. 1
    인쇄할 파일을 연 뒤 위쪽 [파일] → [인쇄]를 누르세요. 키보드 Ctrl과 P를 같이 눌러도 돼요. 인쇄 설정 창이 나와요.
  2. 2
    프린터에서 흑백출력 또는 컬러출력 프린터를 선택하세요.
    💡 워드·엑셀에는 색이나 컬러를 따로 고르는 칸이 없어요. 컬러로 뽑고 싶으면 컬러출력 프린터를 선택하면 돼요. 미리보기가 흑백으로 보여도 정상이에요.
  3. 3
    오른쪽 미리보기에서 내용이 빠짐없이 다 있는지 확인하세요. 표나 글이 잘리지 않았는지, 모든 페이지가 있는지 꼭 보세요.
  4. 4
    아래 옵션을 고르거나 확인하세요. 인쇄할 페이지 · 인쇄 매수(복사본) · 단면 / 양면(양면은 긴 면 · 짧은 면 방향 확인) · 용지 크기 · 가로 / 세로
  5. 5
    용지 크기를 바꿔서 뽑을 때(예: A4 → A3)는 [프린터 속성]에서 원본 문서 크기와 출력 용지 크기를 각각 정하세요.
  6. 6
    모든 옵션을 정했으면 [인쇄] 버튼을 누르세요. 개인식별번호 입력창이 나와요.
워드 · 엑셀 인쇄 옵션은 여기까지예요! [인쇄]를 누르면 개인식별번호 입력창이 나와요.위 ‘인쇄하는 방법’ 2단계(비밀번호 4자리 입력)부터 이어서 하세요 ⬆
  1. 1
    인쇄 매수(복사본)를 정하세요.
  2. 2
    프린터: 빨간 ▼ 버튼을 누른 뒤 [더보기]를 눌러요. 프린터 목록에서 흑백출력 · 컬러출력 · 증명서전용 중 하나를 선택하세요.
  3. 3
    인쇄할 슬라이드: ▼ 버튼을 누르고 인쇄할 슬라이드를 고르세요.
  4. 4
    한 면에 인쇄할 슬라이드 수: ▼ 버튼을 누르고 고르세요. 고른 뒤 미리보기로 꼭 확인하세요.
  5. 5
    단면 / 양면: ▼ 버튼을 누르고 고르세요. 양면은 긴 면 · 짧은 면 인쇄 방향을 확인한 뒤 선택하세요.
  6. 6
    ⚠️ 컬러: 컬러출력 · 증명서전용 프린터를 골랐다면 이 칸을 꼭 [컬러]로 선택하세요.
    [회색조]로 되어 있으면 컬러출력 프린터를 골라도 흑백으로 출력되는데 금액은 컬러 금액으로 결제돼요. [컬러]로 맞추고 미리보기가 컬러인지 꼭 확인하세요.
  7. 7
    용지 크기를 바꿀 때: [프린터 속성]을 누르세요. 창이 나오면 [용지] 탭에서 [원본 문서 크기]와 [출력 문서 크기]를 둘 다 원하는 용지 크기로 선택하세요.
  8. 8
    모든 옵션을 골랐으면 [인쇄] 버튼을 눌러 진행하세요.
    ⚠️ 설정을 다 한 뒤에 ② 프린터 선택을 바꾸면 옵션이 바뀔 수 있어요. 그때는 모든 옵션을 처음부터 다시 확인하세요.
파워포인트 인쇄 옵션은 여기까지예요! [인쇄]를 누르면 개인식별번호 입력창이 나와요.위 ‘인쇄하는 방법’ 2단계(비밀번호 4자리 입력)부터 이어서 하세요 ⬆

크롬 · 엣지 브라우저 캔바 · 웹 PDF

캔바 · 미리캔버스 · 웹 디자인 프로그램 · 아이패드 메모 앱에서 만든 PDF는 브라우저로 열어서 인쇄하면 정상적으로 인쇄됩니다.

🔎 내 파일이 열린 브라우저를 먼저 확인하세요 엣지와 크롬은 인쇄 화면이 달라요

PC에서 파일이 엣지(Edge)로 열려 있으면 아래 엣지 방법, 크롬(Chrome)으로 열려 있으면 아래 크롬 방법(1~5단계)을 따라 하세요. 개인식별번호를 넣고 인쇄 작업 창 확인(5단계)까지 끝나면, 아래로 내려가 복합기에서 인쇄하기로 이어서 하세요. 엣지 · 크롬 · 알씨 모두 똑같아요.

e엣지(Edge)에서 인쇄하기1~5단계
1
[인쇄] 누르기

브라우저에서 인쇄할 파일이 열린 상태에서 [인쇄] 또는 프린터 모양을 누르세요.

💾 가져온 내 파일을 먼저 매장 PC에 저장한 뒤, 엣지로 열어 놓고 시작하세요.
2
프린터 선택

프린터에서 흑백출력 또는 컬러출력 프린터를 선택하세요.

⚠️ 컬러출력 프린터를 선택했다면 '색' 칸에서 [색]을 선택하고, 오른쪽 미리보기가 컬러로 나오는지 반드시 확인하세요.
3
인쇄 옵션 선택 · 확인

[기타 설정]을 눌러 용지 사이즈, 양면/단면, 한 면에 인쇄할 페이지 수 등 인쇄 옵션을 선택하거나 확인하세요.

4
[인쇄] 누르고 번호 입력

아래쪽 [인쇄] 버튼을 누르면 개인식별번호 입력창이 나와요. 아무 숫자 4자리를 넣으세요. 내 핸드폰 번호 뒤 4자리를 추천해요.

이 번호(PIN번호)는 복합기에서 내 문서를 찾을 때 쓰는 임시 비밀번호 같은 거예요. 꼭 기억하세요!
5
인쇄 작업 창 확인

흑백출력 또는 컬러출력 인쇄 작업 창을 보세요.
목록이 하나도 없으면 인쇄 작업이 복합기로 전송된 상태예요.
목록이 남아 있으면 없어질 때까지 기다려 주세요.

C크롬(Chrome)에서 인쇄하기1~5단계
1
[인쇄] 누르기

인쇄할 파일이 크롬에서 열린 상태에서 [인쇄] 또는 프린터 모양을 누르거나, 키보드 Ctrl과 P를 같이 누르세요.
인쇄 설정 창이 나와요. 왼쪽은 미리보기, 오른쪽은 인쇄 옵션 설정 창이에요.

💾 가져온 내 파일을 먼저 매장 PC에 저장한 뒤, 크롬으로 열어 놓고 시작하세요.
2
프린터(대상) 선택

오른쪽 설정 창에서 '대상'이 프린터를 고르는 곳이에요. 누르면 기본으로 흑백출력 프린터가 나와요.
컬러출력이 안 보이면 아래의 [더보기...]를 누르세요. 전체 프린터 목록이 나와요.
흑백출력 또는 컬러출력 프린터를 선택하세요.

⚠️ 컬러출력 프린터를 선택했다면 '컬러' 칸(레이아웃 아래)에서 [컬러]를 선택하세요. 그리고 왼쪽 미리보기가 컬러인지, 인쇄할 모든 페이지가 컬러로 나오는지 반드시 확인하세요.
3
인쇄 옵션 선택 · 확인

[설정 더보기]를 누르면 용지 크기, 양면, 시트당 페이지 수 등 인쇄 옵션이 나와요. 원하는 대로 선택하거나 확인하세요.

4
[인쇄] 누르고 번호 입력

아래쪽 [인쇄] 버튼을 누르면 개인식별번호 입력창이 나와요. 아무 숫자 4자리를 넣으세요. 내 핸드폰 번호 뒤 4자리를 추천해요.

이 번호(PIN번호)는 복합기에서 내 문서를 찾을 때 쓰는 임시 비밀번호 같은 거예요. 꼭 기억하세요!
5
인쇄 작업 창 확인

흑백출력 또는 컬러출력 인쇄 작업 창을 보세요.
목록이 하나도 없으면 인쇄 작업이 복합기로 전송된 상태예요.
목록이 남아 있으면 없어질 때까지 기다려 주세요.

알씨 사진 · 이미지

사진이나 이미지 파일을 인쇄할 때 사용합니다. 한 장에 여러 장 배치도 가능합니다. 매장 PC 바탕화면의 알씨 아이콘으로 사진을 열면 됩니다.

1
파일 열고 인쇄 메뉴

사진을 알씨로 연 뒤 상단 [메뉴] → [인쇄하기]를 선택합니다. 키보드 Ctrl과 P를 같이 눌러도 돼요

💾 가져온 내 사진을 먼저 매장 PC에 저장한 뒤, 알씨로 열어서 시작하세요.
2
프린터 선택

컬러출력 또는 흑백출력 중에서 고릅니다. 컬러 사진은 반드시 컬러출력을 선택하세요.

3
용지 크기 · 방향

왼쪽 아래 [프린터 설정]을 눌러 용지 크기(A4 · A3 등)와 세로 / 가로를 정합니다.

4
크기 설정

[크기설정] 탭에서 용지 크기에 맞춤을 체크하면 사진이 용지에 꽉 차게 인쇄됩니다. 비율을 지키려면 용지 비율에 맞춤을 선택하세요.

5
여백 · 위치

[여백/위치] 탭에서 위 · 아래 · 좌 · 우 여백(mm)과 사진을 놓을 위치를 정합니다.

6
장 수 정하고 인쇄

[기타] 탭에서 인쇄할 장 수를 정하세요. 왼쪽 미리보기로 전체를 확인한 뒤 [인쇄]를 누르세요.

7
[인쇄] 누르고 번호 입력

[인쇄]를 누르면 개인식별번호 입력창이 나와요. 아무 숫자 4자리를 넣으세요. 내 핸드폰 번호 뒤 4자리를 추천해요.

이 번호(PIN번호)는 복합기에서 내 문서를 찾을 때 쓰는 임시 비밀번호 같은 거예요. 꼭 기억하세요!
8
인쇄 작업 창 확인

흑백출력 또는 컬러출력 인쇄 작업 창을 보세요.
목록이 하나도 없으면 인쇄 작업이 복합기로 전송된 상태예요.
목록이 남아 있으면 없어질 때까지 기다려 주세요.

복합기에서 인쇄하기 엣지 · 크롬 · 알씨 공통

PC에서 개인식별번호를 넣고 인쇄 작업을 보낸 뒤에 하는 단계예요. 엣지, 크롬, 알씨 모두 똑같아요.

복1
복합기에서 인쇄 → PC → 번호 입력

복합기로 이동해서 [인쇄] → [PC]를 누르세요.
PIN번호 입력란에 PC에서 넣은 4자리 번호를 입력하고 [OK]를 터치하세요.

복2
내 문서 목록 확인

목록이 나오면 문서 이름, 작업 시간, 흑백/컬러, 양면/단면, 페이지 수, 용지 사이즈 등 목록에 나오는 내용을 꼼꼼히 확인하세요.
내 문서가 맞는지, 인쇄 옵션이 원하는 대로 되어 있는지 봐 주세요.

복3
목록 누르고 [시작]

내 문서 목록을 터치한 뒤 [시작] 버튼을 터치하세요.
목록이 여러 개라면 위쪽의 [모두 인쇄]를 누르거나, 인쇄할 목록만 여러 개 터치한 뒤 [시작]을 누르세요.

복4
금액 확인 (과금정보)

마지막으로 과금정보 창이 나와요. 내용을 모두 꼼꼼히 확인하고, 가격까지 맞으면 [확인]을 터치하세요.

⚠️ 과금정보 창의 페이지 수나 금액이 내가 알고 있는 것과 다르면 결제하지 마세요.
복5
카드 결제

"카드를 대 주세요" 소리가 나오면 신용·체크카드는 단말기에 꽂고, 삼성페이는 터치해서 결제하세요.
