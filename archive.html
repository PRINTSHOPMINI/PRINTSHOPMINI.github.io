비교할 때 확인할 점

기존 서비스 페이지와 기존 사용방법 페이지가 서로 다르게 적혀 있던 부분입니다. 어느 쪽이 맞는지 확인해 새 페이지를 고쳐 주세요.

인쇄

  • 서비스: 프린터선택 → PIN입력 → 복합기 이동 → PIN검색 → 과금확인 → 카드결제 (텍스트 + 화면 사진)
  • 사용방법: PC·프린터선택 → 옵션설정·미리보기 → PIN입력 → 복합기 인쇄→PC → 번호조회·시작 → 확인·결제
  • 서비스에만: 삼성/애플페이는 현대카드 마스터만 가능, Letter→A4 안내, 30분 자동삭제 팁
  • → 새 인쇄 페이지에는 두 가지 모두 들어 있어 내용이 겹칩니다. 비교 후 하나로 정리하세요.

복사

  • 서비스: 6단계 (마지막 '출력 완료 — 원본 잊지 말고 가져가세요')
  • 사용방법: 5단계 + ADF에 넣으면 안 되는 원본 + 신분증·통장·여권·책 복사법
  • → 새 복사 페이지는 사용방법 쪽을 기준으로 하고, '원본 챙기기' 안내만 추가했습니다.

스캔

  • 서비스: 원본 → 스캔메뉴(해상도·PDF/JPG) → 금액확인 → 카드결제 → 파일확인(30분 후 자동삭제)
  • 사용방법: 원본 → 스캔메뉴 → 옵션·시작 → 과금정보 → 결제 후 스캔함 확인
  • → 새 스캔 페이지는 사용방법 쪽을 기준으로 하고, '30분 자동삭제 · USB/이메일' 안내를 추가했습니다.

팩스

  • 서비스: 6단계 + 발신만 가능 · 수신 불가 · 국제팩스 안됨
  • 사용방법: 5단계 + QR 전송결과 확인, ADF 최대 30장, 전송 10분 이상 걸릴 수 있음
  • → 새 팩스 페이지는 사용방법 쪽을 기준으로 하고, 발신만 가능 등 제한 안내를 맨 위에 추가했습니다.
